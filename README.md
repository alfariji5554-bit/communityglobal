CommunityGlobal

Aplikasi komunitas berbasis web dengan tampilan terinspirasi WhatsApp iOS.

Teknologi

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js dan Express
- Database: Supabase PostgreSQL

Fitur yang direncanakan

- Registrasi dan login
- Chat dan status
- Saluran komunitas
- Profil pengguna
- Panggilan audio dan video
